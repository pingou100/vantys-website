## 🏗️ Architecture

### Tech Stack
- **Hosting**: Netlify (free tier)
- **CMS**: Decap CMS (open-source, Git-based)
- **Version Control**: GitHub
- **Build System**: Node.js build script
- **Authentication**: Netlify Identity

### How It Works

```
┌─────────────────────────────────────────────────────────────┐
│                    CONTENT EDITING FLOW                      │
└─────────────────────────────────────────────────────────────┘

Olivier edits via CMS          Claude edits via GitHub API
        │                              │
        ▼                              ▼
   CMS Interface              GitHub API Call
   /admin/                    (create_or_update_file)
        │                              │
        └──────────┬───────────────────┘
                   ▼
           content/homepage.json
           (Single source of truth)
                   │
                   ▼
           Git commit to GitHub
                   │
                   ▼
           Netlify detects change
                   │
                   ▼
           Runs: node build.js
           (Generates HTML from JSON)
                   │
                   ▼
           Deploys to CDN
                   │
                   ▼
           Live site updated (~60 seconds)
```

## 🔧 Build Process

### What Happens on Every Deploy

1. **Trigger**: Git push to GitHub (from CMS or Claude)
2. **Netlify detects change** via webhook
3. **Runs build command**: `node build.js`
4. **build.js**:
   - Reads `content/homepage.json`
   - Generates complete `index.html` from template
   - Includes all content dynamically
5. **Netlify deploys** generated files to CDN
6. **Site updates** (~60 seconds total)

### Build Script (build.js)

- **Purpose**: Generate HTML from JSON content
- **Input**: `content/homepage.json`
- **Output**: `index.html`
- **Why**: Allows CMS edits to appear on live site

**Important**: `index.html` is GENERATED. Do not edit it manually - changes will be overwritten on next build.

## 🆘 Troubleshooting

### CMS Changes Not Appearing

**Check:**
1. Netlify **Deploys** tab → Latest deploy succeeded?
2. Wait 1-2 minutes (build + CDN cache)
3. Hard refresh: `Cmd+Shift+R` (Mac) or `Ctrl+Shift+R` (Windows)

**Build Failed?**
1. Check deploy logs in Netlify
2. Look for error in `build.js` execution
3. Verify `content/homepage.json` is valid JSON

### CMS Login Issues

**Check:**
1. Netlify Identity is enabled
2. Git Gateway is enabled
3. You accepted email invitation
4. Using correct email/password

**Fix:**
- Netlify → Identity tab → Resend invitation

### Merge Conflicts

If both Olivier and Claude edit simultaneously:
1. Netlify will show merge conflict
2. Manually resolve in GitHub
3. Or: let one edit finish, then make the other
